# Terminalia v0.2 — Engine Export, Video Stage, Consistency

## What's new

### 1. Game engine export (`terminalia/export.py`)
Every world now exports to:
- **Unreal 5.x**: auto-generated Python macro — run inside the editor, imports all
  GLBs into `/Game/Terminalia/`, spawns actors at world coordinates. Heightmap
  ready for the Landscape tool. (Your UEIntroProject works; CyberpunkGigapack
  content can be merged alongside.)
- **Unity**: C# editor script + manifest (drop into `Assets/Editor/`, menu
  *Terminalia → Build World*). Requires glTFast or UnityGLTF package.
- **Godot 4**: `.tscn` scene with positioned Node3D anchors per object.
- **Generic glTF**: `manifest.json` + per-object GLBs + heightmap for any other
  engine/viewer.

Coordinates: world px × meters_per_pixel = meters; Z-up; UE gets cm conversion.

### 2. Video stage (`terminalia/video.py`)
- **Camera keyframes**: sample the camera path (or auto-orbit layout centroid)
  into Blender render keys.
- **Flythrough generation**: keyframe stills → Wan 2.2 I2V / FLF2V (first+last
  frame) via ComfyUI native templates, or LTX-2 for joint audio+video.
- **Character lock**: Qwen-Image-Edit multi-view character sheets conditioned on
  one reference image — same identity across front/side/profile views.
- **Face swap**: ReActor workflow (already installed in your ComfyUI) with
  CodeFormer restore, keeping a canonical face across every shot.

### 4. Layout stage (`terminalia/layout.py`)
Flat-area scoring (integral-image local std), region-masked site selection with
min-separation and contact validation — the deterministic half of layout; the agent
adds semantic placement on top.

## Consistency strategy (cross-generation identity)

1. **Character sheets**: one reference image → N locked views (Qwen-Image-Edit)
2. **Canonical faces**: ReActor swaps a single approved face onto all renders
3. **Style unification**: TeleStyleV2 transfer toward one style reference
4. **LoRA pinning**: ai-toolkit trains a world-style LoRA; every asset generation
   loads it
5. **Seed discipline**: world seed derives all asset seeds deterministically
